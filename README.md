# CTRL / SHE

CTRL / SHE is a small editorial-style website built as a learning project.

The project starts with only HTML and CSS.  
The goal is to practice building a clean and good-looking website without using JavaScript or TypeScript.

Later, the site may be expanded with JavaScript or TypeScript.

---

## Purpose

This project is mainly about:
- layout and spacing
- typography and readability
- structuring content with semantic HTML
- learning what can be done with CSS alone

---

## Built with

- HTML
- CSS

---

## How to preview the site

1. Clone the repository  
2. Open `index.html` in your browser  

No setup or tools are needed.
